# Interoperability Testing

This guide demonstrates how to ensure TUF .NET works correctly with repositories and metadata created by other TUF implementations (python-tuf, go-tuf, rust-tuf).

## Overview

TUF .NET is designed for seamless interoperability with all compliant TUF implementations. The TUF specification ensures that metadata and repositories created by any implementation can be consumed by any other implementation.

## Metadata Compatibility

### JSON Serialization

All TUF implementations must produce canonical JSON for signature verification. TUF .NET uses the same canonicalization rules as the reference python-tuf implementation:

```csharp
using CanonicalJson;

// TUF .NET produces canonical JSON compatible with all implementations
var metadata = new Root { /* ... */ };
string canonicalJson = CanonicalJsonSerializer.Serialize(metadata);

// This JSON will have identical canonicalization to python-tuf output:
// - Keys sorted lexicographically
// - No unnecessary whitespace
// - Unicode escaping consistent with python json.dumps
```

### Signature Compatibility

TUF .NET supports all signature schemes required by the TUF specification:

| Algorithm | Key Size | TUF .NET Support | python-tuf | go-tuf | Notes |
|-----------|----------|------------------|------------|--------|--------|
| **Ed25519** | 256-bit | ✅ Full | ✅ | ✅ | Recommended for new deployments |
| **RSA-PSS** | 2048-bit+ | ✅ Full | ✅ | ✅ | Legacy support |
| **ECDSA P-256** | 256-bit | ✅ Full | ✅ | ✅ | Good balance of security/performance |

```csharp
// Example: Verify metadata signed by python-tuf using Ed25519
var pythonSignedMetadata = await File.ReadAllTextAsync("python-signed-root.json");
var metadata = CanonicalJsonDeserializer.Deserialize<Metadata<Root>>(pythonSignedMetadata);

// TUF .NET can verify signatures from any compliant implementation
bool isValid = await metadata.VerifySignatureAsync(trustedKeys);
```

## Cross-Implementation Testing

### Testing with Python TUF Repositories

Python TUF is the reference implementation. Testing against python-tuf repositories validates specification compliance:

```csharp
[Test]
public async Task CanConsumeMetadataFromPythonTuf()
{
    // Load root metadata generated by python-tuf
    var pythonRoot = await File.ReadAllBytesAsync("test-data/python-tuf-root.json");
    
    var config = new UpdaterConfig(pythonRoot, new Uri("https://python-tuf-repo.example.com/"))
    {
        LocalMetadataDir = Path.GetTempPath(),
        LocalTargetsDir = Path.GetTempPath()
    };
    
    var updater = new Updater(config);
    
    // Should successfully refresh from python-tuf repository
    await updater.RefreshAsync();
    
    // Verify we can get target info
    var result = await updater.GetTargetInfo("example-target.txt");
    Assert.IsTrue(result.HasValue);
}
```

### Generating Interoperable Metadata

TUF .NET can create metadata that other implementations can consume:

```csharp
using TUF.Repository;

public async Task CreateInteroperableRepository()
{
    var builder = new RepositoryBuilder();
    
    // Add targets that can be verified by any TUF implementation
    var fileContent = "Hello from TUF .NET!"u8.ToArray();
    var targetFile = new TargetFile
    {
        Length = fileContent.Length,
        Hashes = new Dictionary<string, byte[]>
        {
            // Use SHA-256 for maximum compatibility
            ["sha256"] = System.Security.Cryptography.SHA256.HashData(fileContent)
        }
    };
    
    builder.AddTarget("hello.txt", targetFile);
    
    // Sign with Ed25519 for best interoperability
    var signer = new Ed25519Signer(privateKeyBytes);
    await builder.SignAsync("targets", signer);
    
    // Export metadata in standard TUF format
    string targetsJson = builder.GetMetadata("targets");
    
    // This JSON can be consumed by python-tuf, go-tuf, etc.
    await File.WriteAllTextAsync("targets.json", targetsJson);
}
```

## TAP 4 Multi-Repository Interoperability

TUF .NET implements TAP 4 (multi-repository consensus) which provides enhanced interoperability patterns:

```csharp
[Test]
public async Task MultiRepositoryWithMixedImplementations()
{
    var client = new MultiRepositoryClient();
    
    // Configure multiple repositories from different implementations
    var mapConfig = new
    {
        repositories = new
        {
            python_repo = new 
            {
                base_url = "https://python-tuf.example.com/metadata/",
                targets_url = "https://python-tuf.example.com/targets/",
                root = Convert.ToBase64String(pythonTufRoot)
            },
            go_repo = new
            {
                base_url = "https://go-tuf.example.com/metadata/",
                targets_url = "https://go-tuf.example.com/targets/", 
                root = Convert.ToBase64String(goTufRoot)
            },
            dotnet_repo = new
            {
                base_url = "https://dotnet-tuf.example.com/metadata/",
                targets_url = "https://dotnet-tuf.example.com/targets/",
                root = Convert.ToBase64String(dotnetTufRoot)
            }
        },
        mapping = new[]
        {
            new { paths = new[] { "critical/*" }, repositories = new[] { "python_repo", "go_repo", "dotnet_repo" }, threshold = 2 },
            new { paths = new[] { "*" }, repositories = new[] { "python_repo", "go_repo" }, threshold = 1 }
        }
    };
    
    client.LoadConfiguration(JsonSerializer.Serialize(mapConfig));
    
    // Get consensus target info across implementations
    var targetInfo = await client.GetTargetInfoAsync("critical/important-file.exe");
    
    // Only returns target if threshold repositories agree on its metadata
    Assert.IsTrue(targetInfo.HasValue);
}
```

## Testing Methodology

### 1. Golden Dataset Testing

Create test datasets with known good metadata from multiple implementations:

```bash
# Directory structure for interoperability tests
test-data/
├── python-tuf/
│   ├── root.json          # Generated by python-tuf
│   ├── targets.json       # Generated by python-tuf  
│   └── example-file.txt   # Test target
├── go-tuf/
│   ├── root.json          # Generated by go-tuf
│   ├── targets.json       # Generated by go-tuf
│   └── example-file.txt   # Same content, different signatures
└── tuf-dotnet/
    ├── root.json          # Generated by TUF .NET
    ├── targets.json       # Generated by TUF .NET
    └── example-file.txt   # Same content, TUF .NET signatures
```

```csharp
[TestFixture]
public class InteroperabilityGoldenTests
{
    [TestCase("python-tuf")]
    [TestCase("go-tuf")]  
    [TestCase("tuf-dotnet")]
    public async Task CanReadMetadataFromImplementation(string implementation)
    {
        var rootPath = $"test-data/{implementation}/root.json";
        var targetsPath = $"test-data/{implementation}/targets.json";
        
        var rootBytes = await File.ReadAllBytesAsync(rootPath);
        var root = CanonicalJsonDeserializer.Deserialize<Metadata<Root>>(
            Encoding.UTF8.GetString(rootBytes));
        
        // Should parse successfully regardless of which implementation created it
        Assert.IsNotNull(root);
        Assert.AreEqual("root", root.Signed.Type);
        
        // Should be able to verify signatures
        var isValid = await root.VerifySignatureAsync(root.Signed.Keys.Values);
        Assert.IsTrue(isValid);
    }
}
```

### 2. Round-Trip Testing

Verify that metadata created by TUF .NET can be consumed by other implementations:

```csharp
[Test]
public async Task RoundTripCompatibilityTest()
{
    // Create metadata with TUF .NET
    var builder = new RepositoryBuilder();
    var signer = new Ed25519Signer(testPrivateKey);
    
    builder.AddTarget("test-file.txt", new TargetFile 
    { 
        Length = 100,
        Hashes = new() { ["sha256"] = testFileHash }
    });
    
    await builder.SignAsync("targets", signer);
    string targetsJson = builder.GetMetadata("targets");
    
    // Write to file
    await File.WriteAllTextAsync("dotnet-targets.json", targetsJson);
    
    // Verify python-tuf can read it (requires Python environment)
    var pythonScript = @"
import json
from tuf.api.metadata import Metadata

with open('dotnet-targets.json', 'r') as f:
    metadata = Metadata.from_bytes(f.read().encode())
    
print('Python TUF successfully parsed TUF .NET metadata')
print(f'Found {len(metadata.signed.targets)} targets')
";
    
    await File.WriteAllTextAsync("test_dotnet_metadata.py", pythonScript);
    
    // Run Python interoperability test
    var result = await RunPythonScript("test_dotnet_metadata.py");
    Assert.IsTrue(result.Contains("successfully parsed"));
}
```

### 3. Signature Verification Cross-Testing

Verify signatures created by one implementation can be verified by another:

```csharp
[Test]
public async Task CrossImplementationSignatureVerification()
{
    // Load metadata signed by python-tuf
    var pythonSignedJson = await File.ReadAllTextAsync("test-data/python-signed-root.json");
    var pythonMetadata = CanonicalJsonDeserializer.Deserialize<Metadata<Root>>(pythonSignedJson);
    
    // Load metadata signed by go-tuf  
    var goSignedJson = await File.ReadAllTextAsync("test-data/go-signed-root.json");
    var goMetadata = CanonicalJsonDeserializer.Deserialize<Metadata<Root>>(goSignedJson);
    
    // Load the same public key used by both implementations
    var sharedPublicKey = await LoadSharedTestKey();
    
    // TUF .NET should verify signatures from both implementations
    var pythonValid = await pythonMetadata.VerifySignatureAsync(new[] { sharedPublicKey });
    var goValid = await goMetadata.VerifySignatureAsync(new[] { sharedPublicKey });
    
    Assert.IsTrue(pythonValid, "Could not verify python-tuf signature");
    Assert.IsTrue(goValid, "Could not verify go-tuf signature");
}
```

## Continuous Integration Testing

Integrate interoperability testing into your CI pipeline:

```yaml
# .github/workflows/interoperability.yml
name: Interoperability Testing

on: [push, pull_request]

jobs:
  interop-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

          dotnet-version: '8.0.x'
          
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
          
      - name: Install python-tuf
        run: pip install tuf
        
      - name: Setup Go  
        uses: actions/setup-go@v4
        with:
          go-version: '1.21'
          
      - name: Install go-tuf
        run: go install github.com/theupdateframework/go-tuf/cmd/tuf@latest
        
      - name: Build TUF .NET
        run: dotnet build
        
      - name: Run interoperability tests
        run: dotnet test TUF.InteroperabilityTests/
```

## Troubleshooting Interoperability Issues

### Common Problems

1. **JSON Canonicalization Differences**
   ```csharp
   // Verify canonical JSON output matches reference implementation
   var metadata = new Root();
   var canonicalJson = CanonicalJsonSerializer.Serialize(metadata);
   
   // Should match python json.dumps(separators=(',', ':'), sort_keys=True)
   Console.WriteLine($"Canonical JSON: {canonicalJson}");
   ```

2. **Signature Format Mismatches**
   ```csharp
   // Ensure signature format matches specification
   var signature = await signer.SignAsync(canonicalBytes);
   
   // Ed25519 signatures should be 64 bytes
   Assert.AreEqual(64, signature.Length);
   
   // Should be hex-encoded in metadata
   string hexSignature = Convert.ToHexString(signature).ToLowerInvariant();
   ```

3. **Hash Algorithm Compatibility**
   ```csharp
   // Use SHA-256 for maximum compatibility
   var sha256 = System.Security.Cryptography.SHA256.HashData(fileBytes);
   var targetFile = new TargetFile
   {
       Length = fileBytes.Length,
       Hashes = new Dictionary<string, byte[]>
       {
           ["sha256"] = sha256
           // Other implementations may not support SHA-3, BLAKE2, etc.
       }
   };
   ```

### Debugging Tools

```csharp
public static class InteroperabilityDebugger
{
    public static async Task CompareMetadata(string dotnetJson, string otherImplJson)
    {
        // Parse both metadata files
        var dotnetMeta = CanonicalJsonDeserializer.Deserialize<Metadata<Root>>(dotnetJson);
        var otherMeta = CanonicalJsonDeserializer.Deserialize<Metadata<Root>>(otherImplJson);
        
        // Compare canonical forms
        var dotnetCanonical = CanonicalJsonSerializer.Serialize(dotnetMeta.Signed);
        var otherCanonical = CanonicalJsonSerializer.Serialize(otherMeta.Signed);
        
        if (dotnetCanonical != otherCanonical)
        {
            Console.WriteLine("Canonical JSON differs:");
            Console.WriteLine($"TUF .NET: {dotnetCanonical}");
            Console.WriteLine($"Other:    {otherCanonical}");
        }
        
        // Compare signatures
        Console.WriteLine($"TUF .NET signatures: {dotnetMeta.Signatures.Count}");
        Console.WriteLine($"Other signatures:    {otherMeta.Signatures.Count}");
    }
}
```

## Best Practices

1. **Always test with reference implementation**: Validate against python-tuf when possible
2. **Use standard algorithms**: Prefer Ed25519, SHA-256 for maximum compatibility  
3. **Validate canonical JSON**: Ensure identical canonicalization across implementations
4. **Test signature verification**: Verify cross-implementation signature compatibility
5. **Monitor specification updates**: Stay current with TUF specification changes
6. **Use conformance tests**: Run official TUF conformance test suite regularly
