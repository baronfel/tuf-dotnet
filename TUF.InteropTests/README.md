# TUF .NET Interoperability Tests

This test project validates interoperability between the .NET TUF implementation and other TUF implementations, particularly the reference python-tuf implementation.

## Purpose

These tests address a key gap identified in the TUF .NET parity analysis: **Interoperability Testing**. Specifically:

- Validates that .NET TUF can consume repositories created by python-tuf
- Ensures signature verification works across implementations  
- Tests JSON serialization compatibility
- Verifies consistent metadata handling between implementations

## Test Structure

### PythonTufInteropTests

Core interoperability test class with the following test scenarios:

1. **CanParseRootMetadataFromPythonTuf**: Tests JSON parsing compatibility
2. **CanVerifySignaturesFromPythonTuf**: Validates cryptographic signature verification
3. **CanPerformUpdateWorkflowAgainstPythonTufRepository**: End-to-end workflow validation
4. **JsonSerializationIsCompatibleWithPythonTuf**: Canonical JSON compatibility

## Setup and Usage

### Prerequisites

- .NET 8.0 or later
- Python 3.8 or later (for test data generation)
- python-tuf package

### Quick Setup

Run the automated setup script:

```bash
# From the project root
./TUF.InteropTests/Scripts/setup-python-env.sh
```

This will:
1. Create a Python virtual environment
2. Install python-tuf and dependencies
3. Generate test repository data

### Manual Setup

If you prefer manual setup:

```bash
# Create Python virtual environment
cd TUF.InteropTests/Scripts
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install "tuf[signatures]>=5.0.0" cryptography

# Generate test data
python generate-python-tuf-test-data.py
```

### Running Tests

Once test data is generated:

```bash
# From project root
dotnet test TUF.InteropTests
```

The tests will automatically skip if python-tuf test data is not available.

## Test Data Structure

The generated test repository follows standard TUF structure:

```
TestData/python-tuf-repo/
├── metadata/
│   ├── root.json          # Root metadata with keys and roles
│   ├── timestamp.json     # Timestamp metadata
│   ├── snapshot.json      # Snapshot metadata
│   └── targets.json       # Targets metadata
└── targets/
    └── hello-world.txt    # Sample target file
```

## Key Testing Areas

### JSON Format Compatibility

Validates that the .NET implementation can parse JSON metadata generated by python-tuf, ensuring:
- Property name compatibility (_type, version, expires, etc.)
- Nested object structure consistency
- Array handling compatibility
- Date/time format compatibility

### Cryptographic Interoperability

Tests signature verification across implementations:
- Ed25519 signature verification (recommended by TUF spec)
- RSA signature verification (for legacy compatibility)
- ECDSA signature verification (emerging standard)

### Metadata Structure Validation

Ensures consistent interpretation of TUF metadata:
- Role definitions and thresholds
- Key format and encoding
- Delegation handling
- Target file information

## CI Integration

The tests are designed to work in CI environments:

1. **Conditional Execution**: Tests skip gracefully if python-tuf is unavailable
2. **Isolated Environment**: Uses virtual environment for Python dependencies
3. **Reproducible Data**: Generates consistent test repositories
4. **Cross-Platform**: Works on Linux, macOS, and Windows

## Troubleshooting

### Python Dependencies

If you encounter Python dependency issues:

```bash
pip install --upgrade "tuf[signatures]>=5.0.0" cryptography
```

### Test Data Generation

If test data generation fails:

1. Ensure Python virtual environment is activated
2. Verify python-tuf installation: `pip show tuf`
3. Check Python version compatibility (3.8+)

### Signature Verification

For signature verification issues:

1. Check key format compatibility
2. Verify canonical JSON serialization
3. Ensure hash algorithm consistency
